moodiary

每天记录日常的私人日记 App——像 ins 一样发图配文,但只写给自己。通过 MCP 让 Claude Code 读取日记,生成每周回顾。

设计约定
  • 纯私人:无关注、点赞、评论
  • Claude 读取默认开启,无需开关
  • 导出 Markdown 入口在「我的」
  • 静态设计稿,共 12 屏,可平移缩放
